# Andaman Land CMS

ชุดเว็บไซต์นี้มีหน้ารายการบ้าน และหน้าหลังบ้านสำหรับเพิ่ม แก้ไข หรือลบประกาศได้ที่ `/admin/`.

## เริ่มใช้งานบน Netlify

1. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub repository ที่เชื่อมกับไซต์ Netlify
2. ใน Netlify ไปที่ `Integrations` แล้วเปิดใช้ **Netlify Identity**
3. ในหน้า Identity เลือก `Registration preferences` เป็น `Invite only` เพื่อไม่ให้บุคคลอื่นสมัครเข้าใช้งานเอง
4. ที่ `Identity > Services` เปิด **Git Gateway** และอนุญาตให้ Netlify เข้าถึง GitHub repository
5. เชิญอีเมลของคุณจากหน้า Identity แล้วเปิด `https://ชื่อเว็บไซต์.netlify.app/admin/`

เมื่อบันทึกการเปลี่ยนแปลงจากหน้าหลังบ้าน Netlify จะบันทึกข้อมูลและรูปลง GitHub และเผยแพร่เว็บไซต์เวอร์ชันใหม่โดยอัตโนมัติ

## ช่องข้อมูลในหลังบ้าน

- ชื่อประกาศ
- ทำเล
- ราคา (บาท)
- รูปภาพหลัก
- ห้องนอน, ห้องน้ำ, พื้นที่
- รายละเอียด
