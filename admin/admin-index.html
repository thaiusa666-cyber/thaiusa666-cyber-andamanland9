ลูกค้าที่ติดต่อเข้ามา

ข้อมูลจากฟอร์ม ไม่ได้เก็บไว้ในเบราว์เซอร์นี้ จะไปอยู่ที่ไหนขึ้นอยู่กับวิธีที่ตั้งฟอร์มไว้:

Netlify Forms (ค่าเริ่มต้น)

Netlify → เว็บของคุณ → เมนู Forms → ดูที่ property-enquiry และ contact ควรตั้งแจ้งเตือนทางอีเมลไว้ที่นั่นด้วย เพื่อให้ลูกค้าใหม่เด้งเข้าอีเมลทันที แต่ละรายการจะมีรหัสประกาศ ชื่อ สัญชาติ อีเมล WhatsApp ช่องทางที่สะดวก และข้อความติดต่อมาครบ

ถ้าใช้บริการฟอร์มอื่น

ถ้าตั้งค่า SITE["form_endpoint"] ใน src/data.py ไว้ (เช่น Formspree, Getform หรือ API ของคุณเอง) รายชื่อลูกค้าจะไปอยู่ที่แดชบอร์ดของบริการนั้นแทน

เชื่อมกับเว็บไซต์ของคุณ

เชื่อมหลังบ้านนี้กับ GitHub repository ของคุณเพียงครั้งเดียว จากนั้นปุ่ม บันทึก และ เผยแพร่ขึ้นเว็บ จะเขียนตรงเข้าเว็บจริงทันที — ไม่ต้องดาวน์โหลด ไม่ต้อง copy-paste ไม่ต้องเปิด Terminal Netlify จะ build ให้อัตโนมัติทุกครั้งที่หลังบ้านนี้ commit การเปลี่ยนแปลง

วิธีขอ token (ทำครั้งเดียว ใช้เวลา 2 นาที)

  1. เข้า github.com/settings/personal-access-tokens/new (ล็อกอิน GitHub ก่อน)
  2. Repository access → เลือก Only select repositories → เลือกเฉพาะ repo ของ Andaman Land
  3. Permissions → Repository permissions → ตั้ง Contents เป็น Read and write ที่เหลือปล่อย No access
  4. ตั้งวันหมดอายุ (90 วันก็พอ — หมดแล้วค่อยสร้างใหม่) แล้วกด Generate token
  5. คัดลอก token (ขึ้นต้นด้วย github_pat_…) มาแปะด้านบน แล้วกด เชื่อมต่อ & ทดสอบ
Token จะถูกเก็บไว้ใน เบราว์เซอร์เครื่องนี้เท่านั้น — ส่งตรงไปที่ GitHub API เท่านั้น ไม่แชร์ข้ามอุปกรณ์ ถ้าใช้หลังบ้านนี้จากเครื่องอื่นหรือมือถือ ให้เชื่อมใหม่ด้วย token เดิม (หรือสร้างใหม่ก็ได้) ถ้า token หลุด ให้ไป revoke ที่หน้า GitHub settings เดิมทันที

ยังไม่พร้อมเชื่อม GitHub?

ทำงานแบบออฟไลน์ได้เหมือนเดิม: แก้ข้อมูลประกาศด้านล่าง แล้วกด ดาวน์โหลด JSON ด้านบน วางทับ data/properties.json รัน python3 build.py แล้วอัปโหลด dist/ เอง การเชื่อม GitHub แค่ช่วยตัดขั้นตอนพวกนี้ออกไป

วิธีใช้งาน

เมื่อเชื่อม GitHub แล้ว (แนะนำ — ตั้งครั้งเดียวในแท็บ Connect)

  1. เพิ่มหรือแก้ไขประกาศ กด Save property
  2. กด เผยแพร่ขึ้นเว็บ มุมขวาบน
  3. Netlify จะ build ให้อัตโนมัติ รีเฟรชหน้าเว็บจริงในอีก ~1 นาทีเพื่อดูผล

ยังไม่ได้เชื่อม

  1. เพิ่มหรือแก้ไขประกาศ กด Save property
  2. กด ดาวน์โหลด JSON มุมขวาบน
  3. นำไฟล์ที่ดาวน์โหลดมาวางทับ data/properties.json ในโปรเจกต์
  4. รัน python3 build.py ในโฟลเดอร์โปรเจกต์
  5. อัปโหลดโฟลเดอร์ dist/ ขึ้น Netlify (หรือ push ขึ้น Git แล้วให้ build เอง)

ไม่มีฐานข้อมูล ไม่มีเซิร์ฟเวอร์ ไม่มีค่าใช้จ่ายรายเดือน ทุกหน้าเป็น HTML จริง Google จึงอ่านชื่อประกาศ ราคา ทำเล และคำบรรยายได้โดยไม่ต้องรัน JavaScript
