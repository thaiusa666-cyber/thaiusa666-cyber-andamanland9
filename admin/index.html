How this works

  1. Open this page, add or edit a property, press Save.
  2. Press Download properties.json at the top right.
  3. Replace data/properties.json in the project with the downloaded file.
  4. Run python3 build.py in the project folder.
  5. Upload the dist/ folder to Netlify (or push to Git and let it build).

No database, no server, no monthly fee. Pages are real HTML, so Google reads the title, price, location and description without running JavaScript.

Images

Put photos in assets/img/ with descriptive, SEO-friendly filenames such as land-for-sale-thalang-phuket-001.jpg — never IMG_1234.jpg. In the property editor add each image as a path (/assets/img/your-file.jpg) plus an ALT text that honestly describes the photo. If a property has no images, the site falls back to a generated illustration so nothing is broken.

Rule: never invent data

Leave price, size, coordinates and utilities empty until you have the real figures. Empty fields render as "Price on application" instead of a made-up number. Delete the sample flag once a listing holds real information.
